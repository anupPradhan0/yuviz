# Design: Dynamic, latency-aware first-turn filler

## Approach
At the existing turn-1 branch (`services/conversation/pipeline.py:784-788`) replace the fixed `t("first_turn_filler", ...)` string with a call to the shared `FillerSelector.select_tool_filler`, fed by a new read-only `ToolLatencyStore.agent_average_ms(tenant_id, agent_id)`. That method returns the mean of the existing per-tool `average_ms` values for the agent's tools, skipping tools that return None (Open question 1 assumption: mean, not slowest). It returns None when no tool has usable history, so the selector's existing `_DEFAULT_TARGET_S` path handles a new agent, a restart and an empty window with no new code. The chosen phrase is written to `SessionState.tool_call_filler_last_phrase`, so the existing last-phrase avoidance at `pipeline.py:1323-1328` keeps the same-turn tool filler from repeating it. We reuse `select_tool_filler` and do not add a `select_first_turn_filler`. A second method would fork the tier logic the PRD says not to fork, and the existing method already has the never-None return, the in-language fallback on exception and the per-language pool.

Scope addendum (language-dynamic architecture): `i18n/__init__.py` stops hardcoding `{"en": en, "hi": hi}`. Instead it discovers every `i18n/<code>.py` once at import time with `pkgutil.iter_modules(__path__)` + `importlib.import_module`, checks each module's shape, and builds `_TABLES` plus a precomputed per-language shortest-filler map. After that, adding a language means adding one file with `STRINGS` and `TOOL_FILLERS`, and both `t()` and the selector pick it up with no code change. The selector's error path returns the session language's own shortest phrase from that map instead of the English `_FALLBACK_FILLER`. Nothing new runs on the call path, because discovery and validation finish before the first call. We chose import-time discovery over an explicit list that a contributor must edit, because the PRD addendum requires no code change per language. A malformed module raises at import, so the service fails to start (and the test suite fails) rather than failing mid-call.

## Data
None. The store is in-memory only, and nothing is persisted.

## Interfaces
- `ToolLatencyStore.agent_average_ms(self, tenant_id: str, agent_id: str) -> float | None`: synchronous and never awaits. The cost is O(keys in that tenant), which `_MAX_KEYS_PER_TENANT = 200` caps. It never reads another tenant's map.
- `i18n.shortest_tool_filler(language: str | None) -> str`: the shortest `TOOL_FILLERS` phrase of `normalize_language(language)`'s table, or English's shortest when that language has no module. Pure dict lookup.
- `i18n._discover(path: Iterable[str], package: str) -> dict[str, ModuleType]` and `i18n._validate(code: str, module: ModuleType) -> None`: private. They are called once at import, and tests call them directly against a temporary package.
- `FillerSelector.select_tool_filler`: signature unchanged. On exception it now returns `shortest_tool_filler(language)` instead of `_FALLBACK_FILLER`. Turn 1 passes `tool_name="first_turn"`, which is used only in the exception log line.

## Risks
- Default-path phrases ("Let me check on that.", "Give me a moment." at `_DEFAULT_TARGET_S = 1.6`) can sound odd after a bare "hello", where "Mm-hmm, one moment." was written to fit any utterance. Mitigation: this is what AC 3 explicitly asks for. Flag it for the web-test listen-through (lesson 23). If product rejects it, the fix is a pool choice, not a design change.
- Per-language fallback: on an internal error the selector used to return English on a hi call. Mitigation: it now returns `shortest_tool_filler(language)` from the import-time map, the `log.exception` in `fillers.py` still fires once (AC 5), and a test parametrized over `_TABLES` keeps the fallback in-language for every discovered language.
- A malformed or stray module in `i18n/` stops the conversation service from starting. Mitigation: this is intended (addendum item 3). `_validate` names the file and the failed rule, names starting with `_` are skipped so helpers can live there, and `test_i18n` imports and validates every real module in CI before deploy.
- A discovered language becomes a capability claim (lesson 46). Mitigation: discovery only selects which spoken strings a session already in that language hears. It does not add the language to agent config or provider routing, and the docs say that explicitly.
- Discovery relies on `pkgutil.iter_modules` seeing the files. Mitigation: the service ships as plain source files (no zipapp), and the "en must be discovered" check fails startup loudly if it ever sees nothing.
- LRU side effect: calling `average_ms` per tool moves the agent's keys to the MRU end on every turn 1. Mitigation: this is the same effect as the tool-filler read at `pipeline.py:1320`. It only reorders keys within the caller's own tenant, and recording and windowing are unchanged.
- Dead air before first audio (lesson 51): the lookup adds a dict scan before the first TTS chunk. Mitigation: it is pure in-memory, bounded at 200 keys, with no await and no I/O.
- Cross-tenant leakage (AC 10, lessons 2 and 36): the shared store and selector are hit concurrently. Mitigation: the lookup indexes only `self._tenants[tenant_id]` and filters on `agent_id`, and the selector keeps no per-call state (the phrase lives on the per-session `SessionState`).

## Test plan
Unit and handler-level tests only. All of them use the deployed `TOOL_FILLERS`, `_DEFAULT_TARGET_S`, `_MIN_SAMPLES` and `_MAX_AGE_S` (lesson 25). Seed latency through `record()` with at least `_MIN_SAMPLES` samples, and patch nothing in the tuning.
1. `test_tool_latency.py`, store: `agent_average_ms` returns the mean of per-tool averages across two tools. It ignores a tool below `_MIN_SAMPLES`, returns None when there is no history or the ids are empty, and does not see the same `agent_id` under another tenant (AC 10).
2. `test_pipeline.py`, tiers: seed agent A at about 1000 ms and agent B at about 2400 ms in one shared store for one tenant. Assert that each handler's first TTS text is in the matching `en.TOOL_FILLERS` tier (1.0 versus 2.4) (AC 1, 2).
3. `test_pipeline.py`, fallbacks: with `latency_store=None`, with an empty store, and with a selector whose internals raise (patch `random.choice` to raise), turn 1 still synthesises exactly one filler and the exception is logged once (AC 3, 4, 5).
4. `test_pipeline.py`, repeat avoidance: a turn-1 LLM stream that emits `ToolCallStartedEvent`, with a seeded latency whose tier has a single phrase. The tool-call filler must differ from the turn-1 filler (AC 8). Keep the existing "filler is first and spoken once across two turns" assertions, using the phrase actually spoken on turn 1 (AC 7).
3a. `test_pipeline.py`, direct `latency_store=None` turn 1: build the handler with `latency_store=None`, spy on `FillerSelector.select_tool_filler`, and assert one call with `average_ms=None` and the session language. The first TTS text must be in the `_DEFAULT_TARGET_S` tier and nothing raises. This is separate from the parametrized default-tier test, so the None branch is pinned on its own.
5. `test_multilingual.py`: a hi session gets its turn-1 phrase from `hi.TOOL_FILLERS`. A language with no table (for example "fr") gets an `en.TOOL_FILLERS` phrase (AC 6). Barge-in (AC 9) is covered by the existing cancel tests, since the streaming path is unchanged. Confirm in the web test by ear.
6. `test_i18n.py`, discovery of a fake language: write `en.py` (copied from the real one) and `xx.py` (valid `STRINGS`, a 3-tier `TOOL_FILLERS`) into a `tmp_path` package and call `_discover` on it. Then `monkeypatch` `i18n._TABLES` and `i18n._SHORTEST` with the result and assert: `t(key, "xx")` returns the xx string; a key missing in xx falls back to English; `FillerSelector().select_tool_filler("t", None, ms, language="xx")` returns the expected xx tier for a low, a mid and a high `ms`; and `shortest_tool_filler("xx-YY")` is xx's shortest phrase. None of this edits production code.
7. `test_i18n.py`, validation: parametrized malformed `xx.py` variants (missing `TOOL_FILLERS`, empty `TOOL_FILLERS`, a seconds value as a string, `nan` or 0, a non-en `STRINGS` key such as a typo, a module named `english`) each make `_discover` raise `ValueError` naming the module. A real-package test asserts the discovered set equals the `*.py` files in `i18n/` minus `_`-prefixed names.
8. `test_fillers.py` and `test_i18n.py`, fallbacks: parametrized over `i18n._TABLES`, patch `random.choice` to raise, and `select_tool_filler(..., language=code)` returns a phrase from that language's own `TOOL_FILLERS`. An unknown language ("fr", "zz", None) gets English for `t()`, `tool_fillers()` and `shortest_tool_filler()`, and `t("no_such_key", "hi")` still raises `KeyError`.
