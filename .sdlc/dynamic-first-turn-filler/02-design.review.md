[minor] `_validate` checks that a non-en `STRINGS` key exists in `en.STRINGS`, but the design never says that `en` is loaded before the other modules are validated. `pkgutil.iter_modules` returns modules in filename order, so a future `ar.py`, `bn.py` or `de.py` would be validated before `en` is loaded. — 02-design.md Changes row `i18n/__init__.py` (`_discover`/`_validate`) — fix: state that `_discover` imports all modules first, requires `en`, then validates each module against `en.STRINGS`. Add a Test plan 7 case with a valid `de.py`/`bn.py` that sorts before `en`.
